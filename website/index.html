A browser workspace where you approve the next move.

auto-shift wraps Browser Use with a human-in-the-loop approval layer. Every browser action pauses for your explicit consent via one-use IDs with 5-minute expiry. Built for safety-first automation.

Features

Human-in-the-loop

Every browser action requires explicit approval before execution. No surprises.

One-use approval IDs

Each approval request gets a unique ID that expires after 5 minutes. Replay impossible.

Browser Use integration

Built on Browser Use 0.13.10 with Chromium. Reliable, maintained.

Multiple LLM providers

OpenAI and Ollama adapters. Run locally or with cloud models.

Local-first

Binds to 127.0.0.1:8765. No external connections without your consent.

Test suite

Smoke tests, upstream contract tests, and workspace tests included.

How it works

  1. Start a task — Describe what you want the browser to do.
  2. Review actions — Each proposed action shows the selector, URL, and intent.
  3. Approve or deny — Use the one-use ID to authorize. Expires in 5 minutes.
  4. Watch execution — Approved actions run in Chromium via Browser Use.
  5. Iterate — Continue the session or start a new task.

Architecture

Approval Server

FastAPI server on 127.0.0.1:8765. Serves approval UI and manages pending requests.

Browser Driver

Browser Use + Playwright/Chromium. Executes approved actions with full DOM access.

LLM Adapters

OpenAI (GPT-4o, etc.) and Ollama (local models). Pluggable provider interface.

Workspace

Isolated browser profiles per session. Cookies, storage, history don't leak.

Install

$ pip install -r requirements.txt
$ python -m playwright install chromium
$ python launch.py "your task here"

Requires Python 3.12+. Uses requirements.txt for pinned dependencies.
