04 / Know the scope

Clear expectations.

First implementation. Real account sign-in and a complete model-driven task still require acceptance testing. This does not connect to ChatGPT’s browser or reuse its subscription.

Check the latest results in GitHub Actions. A passing automated check covers its tested paths, not every real-world integration.
